What ALT is.

ALT is a launchpad on Robinhood Chain built on Pons. A coin on ALT is paired to an anonymous X account — an alt. Anyone can launch a coin on any public account; the account doesn't have to agree and doesn't have to know. Every trade pays a fee, and half of it waits in a vault that only that account can open. The account opens it by proving, in public, that it is the account: it posts a code. That is the whole product.

The board on the front page lists real accounts, read live from X. Add any handle and it's read the same way. A row shows followers, and once a coin exists on the alt, its market cap and market cap per follower. Until then the row says "no coin yet". There are no placeholder numbers anywhere on the site.

The rule.

Four lines. Everything else follows from them.

I.Every alt is a coin. Anyone can launch one on any anon.
II.Every trade pays 1%: half waits for the anon, a fifth pays the launcher, the rest is Pons.
III.Only the anon can claim. A post with the code, verified from X.
IV.Market cap per follower, not market cap. Read from the chain and from X, never typed in.

The 1%.

Pons charges 1% on every trade of a coin it launched. Pons keeps 0.3% and pays 0.7% to the coin's creatorFeeRecipient. On ALT the recipient of every coin is the ALT vault wallet, and the vault splits its 0.7% two ways.

0.5%of every trade waits in the anon's vault
0.2%of every trade to the launcher
0.3%of every trade to Pons

Fees are paid in the stock the coin is paired to — the launcher picks it at launch (COIN, NVDA, TSLA, and so on). A coin's 24-hour vault income on the site is volume24 × 0.005 and the launcher's is volume24 × 0.002, with volume24 read from Dexscreener. They are estimates from volume; the actual transfers are the transactions the vault posts.

The vault wallet address is published on the front page and pinned on X at launch. Until then the launch form shows "announced at launch" and the copy button is hidden.

Launching.

Launching happens on Pons; ALT prepares the form and lists the result. The site never touches a wallet.

Pick the alt. Type any X handle. The site reads the account from X's public data and shows the name, avatar and followers so you know you have the right one.

Name the coin, pick the stock. Coin name, ticker, and the stock the coin pays in. Optionally your wallet — it gets the launcher's 0.2%.

Copy the description. The site writes the Pons description in a fixed format (below). It is how we recognise an ALT coin on chain, so paste it unchanged.

Launch on Pons. Open the Pons launch form, paste the description, set the fee recipient to the ALT vault wallet, choose the same stock, and launch.

Register the address. Paste the new contract address back on the site. It's read from Blockscout and Dexscreener on the spot, and a "tell the anon" post is prepared for X.

Listed within the hour. We check the description and the fee recipient on chain and add the coin to the registry. From then on its row reads live.

The description format:

ALT · @handle · pays in $STOCK · launcher 0x… · every trade pays 1%: 0.5% waits in the anon's vault, 0.2% to the launcher, 0.3% to Pons · every alt is a coin.

A coin whose fee recipient is not the ALT vault is not an ALT coin, whatever its description says, and is not listed.

Claiming.

The vault has one key: the account itself. No wallet signature, no DM, no admin. The account proves it's the account by posting a code that only its handle and its chosen wallet can produce.

Code. On the site, enter your handle and the wallet to pay. The code is computed in your browser — nothing is sent anywhere.

Post. Post the code from the account. A reply, a quote, a fresh post — anything public.

Verify. Paste the post's URL. The site reads the post from X's public syndication endpoint and checks two things: the author is your handle, and the text contains the code.

Paid. The vault pays your wallet at the next hourly sweep, the transaction goes into claims.json, and the row turns "claimed".

The code is deterministic, so anyone can recompute it. It is the FNV-1a 32-bit hash of lowercase(handle) + "|" + lowercase(wallet), written in base 36, upper-cased, seven characters, prefixed ALT-:

function hash(s) { let h = 2166136261; for (const c of s) { h ^= c.charCodeAt(0); h = Math.imul(h, 16777619) >>> 0; } return h >>> 0; }
function claimCode(handle, wallet) {
  const h = hash(handle.toLowerCase() + '|' + wallet.toLowerCase());
  return 'ALT-' + h.toString(36).toUpperCase().padStart(7, '0').slice(0, 7);
}

Why not a wallet signature? Because the vault belongs to the account, not to whoever holds a wallet. A wallet can't prove it's @anon. A post from @anon can.

Per follower.

The headline number on every alt is market cap divided by followers, both read live:

per_follower = mcap (Dexscreener, USD) / followers (X, public profile)

A $100K coin on a 10K-follower alt is $10 a follower. A $100K coin on a 1M-follower alt is 10¢ a follower. Market cap says how big a coin is; per follower says how much of the account's audience has been priced in. It is the number to compare alts by, and the reason the board is sorted by it once coins exist.

Followers are cached for five minutes; market cap for thirty seconds. If X doesn't answer for an account, the row says "followers not exposed" and per follower is "—". A dash is never replaced with a guess.

Data readers.

Four small serverless readers on the site's own domain. No API keys, no accounts; they read public endpoints and pass the numbers through. Each one below runs live when you press try.

GET /api/handle?h=<handle>

An X account's public profile. Source: FxTwitter's public user endpoint, with X's follow-button and syndication timeline endpoints as fallbacks. Cached 5 min.

fieldmeaning
followersfollower count
namedisplay name
avatarprofile image URL (the site swaps _normal for _400x400)
verifiedblue check
existstrue, false (no such account) or null (X didn't answer)
srcwhich source answered
GET /api/coin?ca=<address>

A token on Robinhood Chain. Sources: Blockscout (name, symbol, holders, supply) and Dexscreener (price, mcap, liquidity, volume24, change24, chart). Adds vaultIncome24 (volume × 0.005) and launcherIncome24 (volume × 0.002). Cached 30 s. A coin with no Dexscreener pair yet returns "dex": "no pair yet".

GET /api/tweet?id=<id> or ?url=<post url>

A public post. Source: X's syndication tweet-result endpoint, with oEmbed as fallback. Returns author, name, text, created, likes, views, inReplyTo. This is what verifies a claim: the author must equal the handle, the text must contain the code. Cached 20 s.

GET /api/chain

Robinhood Chain stats from Blockscout: block, txs, addresses, gas. Cached 30 s.

All four send Access-Control-Allow-Origin: *, so anyone can read them from anywhere. Source code: github.com/madii506/alt/api.

Not on chain yet.

Two things are done by hand today, and both are posted.

The split. Pons pays the 0.7% to one wallet. That wallet — the ALT vault — pays launchers their 0.2% and holds the anons' 0.5% per alt. It sweeps every hour and every transaction is posted on X and in claims.json. The vault contract that does this automatically is the next thing shipped; the fee recipient of every coin will then be moved to it.

The listing. A launched coin is added to alts.json after a person checks that its description and fee recipient match. That check can be automated from the same Blockscout data the site already reads, and will be.

What is not hand-made: followers, market caps, per-follower prices, holders, volumes, claim verification. If a number can be read, it is read.
